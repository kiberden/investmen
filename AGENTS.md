# AGENTS.md

> Карта проекта для AI-агентов. Обновляйте при существенных изменениях структуры, точек входа или технологического стека.

## Обзор проекта
`investman` — Laravel-приложение для синхронизации и отображения инвестиционных данных через модуль `BrokerGateway`, с запуском в Docker и стеком наблюдаемости Grafana/Loki/Promtail.

Подробное описание целей и контекста находится в `.ai-factory/DESCRIPTION.md`.

## Технологический стек
- **Язык программирования:** PHP 8.4
- **Фреймворк:** Laravel 12
- **База данных:** PostgreSQL 17
- **Очереди/кэш:** Redis + Horizon
- **Admin UI:** MoonShine 4.4

## Структура проекта
```text
.
├── laravel_app/                    # Основное приложение Laravel
│   ├── app/                        # Доменная логика, сервисы, jobs, провайдеры
│   │   ├── Modules/BrokerGateway/  # Интеграции и доменная логика брокеров
│   │   ├── MoonShine/              # UI/admin слой
│   │   └── Providers/              # DI и композиция сервисов
│   ├── config/                     # Конфигурация Laravel
│   ├── routes/                     # HTTP/console маршруты
│   └── tests/                      # Unit/Feature тесты
├── docs/                           # Проектная документация
├── observability/                  # Конфигурации Loki/Promtail/Grafana
├── docker-compose.yml              # Docker-окружение сервисов
└── makefile                        # Автоматизация (линт, формат, тесты, служебные команды)
```

## Ключевые точки входа
| Файл | Назначение |
|------|------------|
| `laravel_app/artisan` | Основная CLI-точка входа Laravel-команд |
| `laravel_app/routes/api.php` | HTTP API маршруты приложения |
| `laravel_app/config/app.php` | Базовая конфигурация Laravel-приложения |
| `docker-compose.yml` | Описание контейнеров приложения и зависимых сервисов |
| `makefile` | Локальные команды разработки и проверки качества |

# AGENTS.md

> Карта проекта для AI-агентов. Обновляйте файл при существенных изменениях структуры или технологического стека.

## Обзор проекта
`investman` — Laravel-проект для синхронизации и отображения инвестиционных данных через модуль `BrokerGateway`, с контейнеризированной инфраструктурой и встроенной наблюдаемостью.

## Технологический стек
- **Язык программирования:** PHP 8.4
- **Фреймворк:** Laravel 12
- **База данных:** PostgreSQL 17
- **Очереди/кэш:** Redis + Horizon
- **Админ-панель:** MoonShine 4.4
- **Наблюдаемость:** Grafana + Loki + Promtail

## Структура проекта
```text
.
├── laravel_app/                  # Основное Laravel-приложение
│   ├── app/                      # Бизнес-логика, модули, сервисы, jobs
│   │   ├── Modules/BrokerGateway # Доменные интеграции с брокерами
│   │   ├── MoonShine/            # UI/admin слой (без интеграционной бизнес-логики)
│   │   └── Providers/            # DI/композиция сервисов
│   ├── routes/                   # HTTP/console/channel маршруты
│   ├── tests/                    # Unit и Feature тесты (PHPUnit)
│   └── config/                   # Конфигурация приложения
├── observability/                # Конфигурация Loki/Promtail/Grafana
├── docs/                         # Дополнительная документация
├── docker-compose.yml            # Основной docker-compose для dev-окружения
└── makefile                      # Команды автоматизации (в т.ч. проверки)
```

## Ключевые точки входа

|------|------------|
| `laravel_app/artisan` | Основная CLI-точка входа Laravel-команд |
