# Project Roadmap

> MVP для управления брокерскими подключениями и портфелями в админке, начиная с REST-интеграции TBank.

## Milestones

- [x] **Базовый домен брокеров и учетных данных** — созданы сущности, миграции и синхронизация credential при сохранении брокера.
- [x] **Интеграционный каркас BrokerGateway + TBank** — реализованы реестр провайдеров, резолверы и базовые клиенты/действия для TBank.
- [x] **Базовый UI в админке для брокеров и счетов** — добавлены ресурсы MoonShine для брокеров и счетов с фильтрацией по текущему пользователю.
- [x] **Конфигурация ключей подключения брокеров** — единый формат хранения нескольких ключей подключения для `tbank`, `alfa`, `sber` с текущей реализацией только `tbank`.
- [x] **Привязка брокера к ключу подключения через select в ресурсе** — при создании/редактировании брокера пользователь выбирает ключ подключения из конфигов.
- [ ] **Резолв API-настроек по выбранному ключу** — сервисы подключения получают параметры через ключ из записи брокера без хардкода.
- [ ] **REST API-подключение как первый рабочий контур** — синхронизация/подключение через REST API с поддержкой `tbank`.
- [ ] **Кнопка к портфелю в листинге брокеров через ресурс** — переход из списка брокеров на портфельный экран по выбранному брокеру пользователя.
- [ ] **Листинг портфеля по пользователю и брокеру** — вывод общей информации по содержимому портфеля в разрезе пользователя и брокера.
- [ ] **Покрытие тестами и регрессионные проверки** — тесты на выбор ключа подключения, резолв конфига, REST-контур и доступы к портфелю.
