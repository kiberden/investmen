# Общее

## Назначение текущего этапа

Собрать базовую инфраструктуру подключения к брокерским шлюзам через provider-модель:

- первый провайдер: `T-Bank`;
- окружения: `prod` и `sandbox`;
- базовые данные: портфель, позиции, операции;
- расширяемость под другие провайдеры.

## Границы ответственности

- Backend интегрируется с брокерским шлюзом через API-клиенты.
- MoonShine используется как UI-слой админки и работает с backend.
- Данные для UI могут читаться из short-term cache и/или из БД.
