# База

## Текущий статус

Схема базы хранится в PlantUML-файле:

- `database-schema.puml`

Этот файл пока не удалялся и сохраняется как рабочий источник для дальнейшего обновления под provider-архитектуру.

## Что нужно переработать дальше

- формализовать связи доступа:
  - `users -> profiles -> brokers -> brokerCredentials`;
  - контроль видимости подключений только в границах владельца профиля;
- выделить сущности интеграции провайдера (`provider`, `environment`, `external_account_id`);
- уточнить short-term слой хранения:
  - только Redis TTL;
  - или Redis + snapshot таблицы в PostgreSQL;
- зафиксировать правила TTL и инвалидации кэша по аккаунту/провайдеру.

## Учетные данные подключения

- `token + secret` для внешнего шлюза хранятся в `brokerCredentials`.
- `brokers` содержит связь подключения с профилем пользователя и тип провайдера.
- При обращении к шлюзу backend сначала определяет broker в контексте профиля, затем получает активный credential.
